# Fork instructions

- Public repository: never commit service endpoints, credentials, real member IDs,
  profiles, chat transcripts, databases or diagnostic exports.
- Do not use SSH keys or access deployments without explicit permission.
- Use uv for Python environments and dependency management.
- Preserve upstream attribution and license.
- Member computer use stays disabled. Profile editing is an administrator operation.
- Keep human notes separate from generated observations; automatic analysis must
  not overwrite manually maintained notes or locked profile fields.
- Participation decisions must fail closed and obey code-enforced limits. No
  unsolicited messages during development or tests.
